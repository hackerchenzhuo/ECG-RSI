ECG-RSI Recursive Self-Improvement through
Targeted ECG Waveform Evolution

A model’s mistakes suggest what to teach next. ECG-RSI turns those suggestions into measurable waveform changes, then tests which training intervention helps the learner.

The research question

Which ECG example should the model learn from next?

More synthetic data is useful only if its labels agree with the signal and its content addresses a learnable gap.

ECG-RSI separates these decisions: signal measurements check the example; matched training branches test its utility for the current model.

01 / From a target to evidence

Make the waveform carry the lesson.

A PR-interval lesson needs a signal that expresses the intended contrast. ECG-RSI remeasures the edit and builds the answer from the achieved values.

A recorded PR-prolongation example

The pipeline lengthens the PQ segment and compensates in the TP segment to preserve the interval between beats. It then measures the edited signal before constructing the question.

Requested PR
300 ms
Measured PR
298 ms
Measured heart rate
74.6 bpm

What is being verified? Both the requested change and the features that should remain stable. A successful edit alone does not guarantee a valid training question: the image, question, answer and explanation must also agree.

Source: paper appendix, “Case 1: Targeted PR prolongation.”

Another example: slowing the heart rate while preserving the beat waveform

Extending the TP segment increases the interval between beats while retaining the P–QRS–T segment. The requested rate is 48 bpm; the pipeline measures 47.9 bpm. This example provides a different contrast from PR prolongation.

02 / The mechanism

Two kinds of error.
Two places to intervene.

Construction feedback improves how examples are made. Learner feedback proposes what the next training data should teach.

Construction feedback

Can the example support its answer?

Start with an eligible training ECG, or edit it to express a requested feature contrast. Remeasure the signal and check the resulting supervision.

  • Did the target feature change as requested?
  • Were protected features preserved?
  • Do the question and answer match the signal?

↶ Rejections guide repairs to waveform operators, retrieval rules and generation prompts.

Learner feedback

Will this intervention help this model?

Diagnose errors by ECG category, question type, difficulty and recurring confusion. Use these observations to propose candidate training recipes.

  • Reinforce a weak category and its question types.
  • Contrast diagnoses the learner confuses.
  • Adjust the difficulty and task mixture.

↶ Compare trained candidates, retain a qualifying update, then diagnose the updated learner.

A fair comparison starts from the same parent.

  1. 1Propose A / B / C

    Three intervention families respond to the current error profile.

  2. 2Construct and train

    Each branch adds 10,000 accepted questions, with matched replay and training settings.

  3. 3Select an update

    A separate selection set compares candidates and checks regression.

  4. 4Evaluate transfer

    External benchmarks measure the retained learner’s performance.

The feedback set diagnoses weaknesses; the selection set chooses a checkpoint. External benchmarks stay outside generation and selection.

03 / What the experiments show

The next useful intervention can change.

The experiments separate the value of a constructed example from the value of training on it—and track whether local progress transfers.

01

A weakness does not uniquely determine how to teach it.

Each round compares direct reinforcement, confusion contrast and curriculum adjustment. The retained intervention changes from direct reinforcement to confusion-focused contrasts. Error diagnosis proposes a direction; candidate training tests that proposal.

Source: paper, “Round-Wise Branch Selection and Data Composition.”

02

The content of new data matters, beyond its volume.

All four configurations start at S7 = 43.22 and add 10,000 questions. Adding reverse synthesis and feedback-guided selection gives the largest observed improvement in this comparison.

The fixed and feedback-guided bidirectional mixtures differ by 0.67 S7 points. The comparison tests how the added examples are constructed and selected.

Source: paper, “Data Construction and Feedback Selection.”

03

Local correction has diminishing external returns.

Feedback errors continue to fall, but the external S7 gains shrink from 13.07 to 3.01 to 0.38 points. Some individual benchmark scores fall in the final round.

The result motivates checking external transfer and task-level regressions when deciding whether another update is useful.

Source: main benchmark trajectory, series R-A. Model: Qwen3.5-35B-A3B.
